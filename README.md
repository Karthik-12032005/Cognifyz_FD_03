# ShopEase - E-Commerce Landing Page

ShopEase is a modern and responsive E-Commerce Landing Page developed using HTML, CSS, JavaScript, and Bootstrap. The project showcases advanced CSS styling, responsive layouts, animations, and interactive product cards for an attractive online shopping experience.

---

## 🚀 Features

- Responsive Navigation Bar
- Hero Banner Section
- Featured Product Cards
- Hover Animations & Effects
- Interactive Buttons
- Mobile Responsive Design
- Modern UI with Bootstrap
- Smooth Animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
